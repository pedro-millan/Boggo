# Boggo Fresh Bagel · Static Website

Spanish-language web project for Boggo Fresh Bagel, a physical restaurant specialized in bagels.  
Built with HTML, CSS and JavaScript.

## Included Pages

- `index.html` — Home
- `carta.html` — Full menu organized by categories
- `reserva.html` — Table reservation form
- `club.html` — Club Boggo with a points simulator
- `faq.html` — Frequently Asked Questions
- `privacidad.html` — Privacy Policy
- `encuentranos.html` — Location information

## How to Open It

Open `index.html` directly in your browser.

You can also run a local server from the project folder:

````bash
python3 -m http.server 5500

Then open:

http://localhost:5500
Notes
The website only uses images included in the original ZIP file.
The color palette is based on the visible Boggo brand identity: cream, green and dark green.
The reservation form is a frontend simulation and stores data in localStorage. For production, it should be connected to a real backend.

# Boggo Fresh Bagel · Web estática

Proyecto web en español para Boggo Fresh Bagel, restaurante físico especializado en bagels.
Realizado en HTML, CSS Y JAVASCRIPT.

## Páginas incluidas

- `index.html` — Home
- `carta.html` — Carta completa por categorías
- `reserva.html` — Formulario de reserva de mesa
- `club.html` — Club Boggo con simulador de puntos
- `faq.html` — Preguntas frecuentes
- `privacidad.html` — Política de privacidad
- `encuentranos.html` — Información de localización

## Cómo abrirlo

Abre `index.html` directamente en el navegador.

También puedes levantar un servidor local desde la carpeta del proyecto:

```bash
python3 -m http.server 5500
````

Luego entra en:

```txt
http://localhost:5500
```

## Notas

- La web usa únicamente imágenes incluidas en el ZIP original.
- La paleta se ha basado en los colores visibles de la identidad Boggo: crema, verde y verde oscuro.
- El formulario de reserva es una simulación frontend y guarda datos en `localStorage`. Para producción habría que conectarlo a un backend real.
